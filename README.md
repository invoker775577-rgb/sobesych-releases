# Sobesych Windows Releases

Windows installers and in-app updates for Sobesych, a desktop interview practice application.

Download the installer from [the latest release](https://github.com/invoker775577-rgb/sobesych-releases/releases/latest). Install once, then use Settings > Updates in the application.

Source code is maintained separately in a private repository. The Electron installer contains executable application code that can be extracted. No personal API keys, candidate profiles, recordings, or conversation history are distributed here. Each user configures their own AI provider key.

Windows x64. Local speech recognition requires compatible NVIDIA CUDA hardware. The installer currently bundles the speech model/runtime and is large. Windows installers are currently unsigned; only download from this repository. This application is for interview practice.
