# Sobesych Windows Releases

Windows installers and in-app updates for Sobesych, a desktop call assistant with an optional interview practice mode.

Download the installer from [the latest release](https://github.com/invoker775577-rgb/sobesych-releases/releases/latest). Install once, then use Settings > Updates in the application.

The [source code is public under the MIT license](https://github.com/invoker775577-rgb/sobesych-source). You can fork, modify and distribute your own version while preserving the license and copyright notices. Build instructions are in that repository.

No personal API keys, candidate profiles, recordings, or conversation history are distributed here. Each user configures their own AI provider key.

Windows x64. Version 0.5.80 includes a CPU speech engine and model; NVIDIA acceleration is a separate optional download in Settings. CPU transcription can be too slow for a live conversation. Windows installers are currently unsigned; only download from this repository.

The source repository may contain fixes not yet included in the released installer. Publishing source code does not update installed applications. Use AI assistance only where the other participants permit it.
